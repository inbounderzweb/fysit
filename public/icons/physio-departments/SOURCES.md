# Physiotherapy department icons

Original artwork from the Mednix theme icon font, downloaded October 7, 2026, for the About page's "Our Department" carousel.

- Font: [flaticon_mycollection.ttf](https://mednix.themeht.com/wp-content/themes/mednix/assets/fonts/flaticon_mycollection.ttf)
- Glyph mapping: [mednix-icon.css](https://mednix.themeht.com/wp-content/themes/mednix/assets/css/mednix-icon.css)
- The source stylesheet credits [Flaticon](https://www.flaticon.com).

| Local SVG | Original glyph | Code point |
| --- | --- | --- |
| `manual-therapy.svg` | `massage` | `U+F16B` |
| `exercise-therapy.svg` | `physical-therapy-1` | `U+F16C` |

Converted the same way as `../physio-highlights/`: FontTools `SVGPathPen` on the original outlines, 300-unit em square, `fill="currentColor"` so the artwork can serve as a CSS mask. No artwork was redrawn.

`../share-nodes.svg` (glyph `share`, `U+F149`) was converted the same way for the About page team cards; the older `../share.svg` is actually the marquee starburst.
