# Contact page icons

Original artwork from the Mednix theme icon font, downloaded October 13, 2026, for the Contact page's contact list and social links.

- Font: [flaticon_mycollection.ttf](https://mednix.themeht.com/wp-content/themes/mednix/assets/fonts/flaticon_mycollection.ttf)
- Glyph mapping: [mednix-icon.css](https://mednix.themeht.com/wp-content/themes/mednix/assets/css/mednix-icon.css)
- The source stylesheet credits [Flaticon](https://www.flaticon.com).

| Local SVG | Original glyph | Code point |

| `mail.svg` | `email-3` | `U+F117` |
| `phone.svg` | `phone-call` | `U+F10D` |

Converted the same way as `../physio-departments/`: FontTools `SVGPathPen` on the original outlines, `fill="currentColor"` so the artwork can serve as a CSS mask. No artwork was redrawn.
